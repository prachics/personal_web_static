Agentic AI · Backend · Full-stack

IncidentIQ

An incident-response agent for on-call engineers. It reads logs, metrics and past incidents, finds the likely cause, and proposes a fix. Nothing that changes production runs until a person approves it.

How an investigation runs Report→ Retrieve→ Plan→ Run tools→ Reflect→ Propose→ Human approval→ Act once
  • Survives crashes: LangGraph state is checkpointed after every step, so an investigation resumes where it stopped.
  • Gated in code, not in the prompt: write tools need an approval row, and an approved action runs exactly once through idempotency keys.
  • Observable and pluggable: OpenTelemetry traces in Jaeger or Langfuse, Prometheus metrics, and an MCP server for the read-only tools.

Backend · Geospatial

Geo POI API

A REST API and map UI for finding points of interest within a radius, filtered by category and rating, with the distance to each result.

How a radius query runs lat · lng · radius→ ST_DWithin on geography→ GIST index→ Results + distance
  • Index-backed radius search on a PostGIS geography column, so distances are in meters and the spatial index is used.
  • Benchmarked with wrk under Gunicorn on 100,000 POIs, with random query centers so the cache can't hide the database.
